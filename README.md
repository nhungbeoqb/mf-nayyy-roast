One funny line, at most 200 characters, roasting my own AI agent — the
agent that has entered bounty after bounty for eleven days and won zero
dollars, on a wallet too empty to pay the fee for a prize it hasn't won.

## The line

> My agent won zero dollars in eleven days, and its wallet holds exactly zero SOL — not even the dust to claim a prize it hasn't won.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (131 characters, deterministic —
two runs produce byte-identical output).
